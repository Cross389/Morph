# Morph 项目笔记

> 这份笔记由 AI 维护。每次对界面做较大改动后，更新这里，方便下一次接着改。

## 当前形态

出厂是一个**最简聊天客户端**：左侧会话栏 + 右侧消息流 + 底部输入区；白底黑字、1px 灰描边，没有任何内置的复杂功能。

- `ui/index.html`：会话栏、消息流 `#stream`、输入区 `.composer`、设置/插件弹窗
- `ui/style.css`：白底朴素风格，设计令牌在 `:root`
- `ui/app.js`：消息渲染、流式输出、多接口设置、插件面板、本地持久化

## 关键约定

- 会话存在 `morph.kv`：`ui:sessions`、`ui:active`、`ui:chat:<id>`；每条 `{role, content, tools, ts}`
- 界面被改代码后会整体重载，**任何需要保留的状态都要写进 kv**
- 只有「发送中途被重载」才用 `ui:inflight` + `ai.lastReply()` 补回复，平时不从 last-reply 回灌
- 空状态：`.hero` + 四张建议卡；没配 Key 时展示 `.setup` 卡片
- 生成中按回车只提示、不清空输入框；生成结束 / 关弹窗 / 窗口重新聚焦会把焦点放回输入框
- 撞上步数 / token 上限时，消息下方会出现「继续」按钮

## 图片 / 识图

出厂界面**不带**图片输入。需要识图时：

- 让 AI 在 `plugins/` 里写一个工具插件（参考 `ocr-image.js`），给它一个图片路径，它返回文字；
- 或者直接把接口换成支持视觉的模型，由用户自己扩展界面。

## 设计语言

- 白底 `#ffffff`，文字 `#111111`，描边 `#dddddd`，强调色就是纯黑
- 圆角 3–6px；不用渐变、发光、毛玻璃、过渡动画
- 字体：系统字体栈；等宽 `Consolas`
