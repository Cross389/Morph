AI 设置

发给接口的 reasoning_effort 参数。部分模型不支持，会自动忽略。

沙箱：AI 只能读写界面代码。完全权限：可执行系统命令、读写整机、并给自己写插件。

高级设置

发给接口的 max_tokens（单次输出上限）。填 0 表示不发送，交给模型厂商自己的默认/上限；也可以填任意正整数，但超过厂商能力会被服务端拒绝或截断。上下文窗口是另一回事（输入+输出）。

一条消息里 AI 最多连续调用多少次工具（读写文件、执行命令、写插件）。大于 0 的整数都可以；调大适合大规模改造，但更慢、更费钱。

API Key 用 Windows DPAPI 加密后只保存在本机；每个接口各自独立，界面上只能看到末尾四位。

插件

插件放在 %APPDATA%\Morph\plugins\。让 AI 写一个，它写完调用 plugins_reload 就会出现在这里。

插件工具只在「完全权限」下对模型可见，关掉开关就彻底不加载。
